What changed in the final application

  1. The worker-thread test compares Thread identity. Coroutine debug mode can change its displayed name without changing the executing thread. This preserves the test’s purpose instead of weakening it.
  2. The starter instrumentation test now expects the application’s actual package ID rather than com.example.multitasked.
  3. Two deprecated Divider calls use HorizontalDivider.
  4. The generated Room schema is retained so future schema changes can be reviewed.

The first complete unit run had one failure out of 49; the first instrumentation run had one failure out of 11, while all ten Room tests passed. Those failures and subsequent fixes are recorded rather than hidden. Initial unit-run log · Initial instrumentation log · Changed-file list
